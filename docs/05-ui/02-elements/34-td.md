# td

![A score table: the cells of three players, names, scores and times](table.png "ember · table")

```go
ui.Td(ui.Text("12:40"), ui.Attr("data-sort", "760"))
```

| Attribute | |
|---|---|
| `data-sort` | what a grid sorts it by in place of its text |
| `colspan`, `rowspan` | it spans that many columns and rows; a `rowspan` stops at the end of its row group, and `0` spans to it |

| Default CSS | |
|---|---|
| `td` | `padding: 1px` |
