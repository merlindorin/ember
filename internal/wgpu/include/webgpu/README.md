The WebGPU C headers ember's binding is built against, at the wgpu-native release in ../VERSION:

- `webgpu.h`: the standard WebGPU C API from webgpu-native/webgpu-headers, BSD-3-Clause, its notice in the file.
- `wgpu.h`: wgpu-native's extensions (gfx-rs/wgpu-native), dual-licensed MIT or Apache-2.0: `LICENSE-wgpu-native.MIT` and `LICENSE-wgpu-native.APACHE`. The wgpu-native library a game ships beside it comes under the same licences.
