# h3

![Controls in bold, a little larger than the line of body text under it](h3.png "ember · h3")

```go
ui.H3(ui.Text("Controls"))
ui.P(ui.Text("Keyboard and gamepad bindings."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

| Default CSS | |
|---|---|
| `h3` | `display: block; margin: 1em 0; font-size: 1.17em; font-weight: bold` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element h3
```
