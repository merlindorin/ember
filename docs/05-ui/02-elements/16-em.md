# em

![The cellar door is locked, locked in italic](em.png "ember · em")

```go
ui.P(ui.Text("The cellar door is "), ui.Em(ui.Text("locked")), ui.Text("."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

| Default CSS | |
|---|---|
| `em` | `font-style: italic` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element em
```
