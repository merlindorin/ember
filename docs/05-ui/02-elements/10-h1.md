# h1

![Inventory in large bold over a line of body text](h1.png "ember · h1")

```go
ui.H1(ui.Text("Inventory"))
ui.P(ui.Text("Twelve slots, four of them free."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

| Default CSS | |
|---|---|
| `h1` | `display: block; margin: 0.67em 0; font-size: 2em; font-weight: bold` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element h1
```
