# tr

![A score table: four rows, the header and three players](table.png "ember · table")

```go
ui.Tr(ui.Td(ui.Text("Ayla")), ui.Td(ui.Text("4210")), ui.Td(ui.Text("12:40")))
```

A row of `th` and `td` cells, in a `thead`, a `tbody` or the table itself; as tall as its tallest cell.

| Attribute | |
|---|---|
| `aria-selected="true"` | a grid's selected row, set by the grid |
| `aria-disabled="true"` | in a grid, dimmed and skipped |

| Default CSS | |
|---|---|
| `tr` | none |

A row's background paints behind its own cells only: a cell spanning rows keeps its first row's background over its whole box, and the `border-spacing` gaps show what's under the row, as in Chrome.

| Event | When |
|---|---|
| `ui.Changed{Node}` | for its grid, when a click or a key selects it |
| `ui.Submitted{Node}` | for its grid, when Enter, Space, the pad's South or a double click activates it |

Automation: a grid's body row, by its `id`, else `data-name`, `aria-label`, then the slug of its first cell (`ayla`); `press` (selects and activates) and `select`.
