# p

![Two paragraphs of a quest log, wrapped, the second right under the first](p.png "ember · p")

```go
ui.P(ui.Text("The miller's daughter has not come home. Her lantern was found by the old bridge."))
ui.P(ui.Text("Search the riverbank before nightfall."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text, wrapped to its width; children may be any inline elements |

| Default CSS | |
|---|---|
| `p` | `display: block; margin: 1em 0` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element p
```
