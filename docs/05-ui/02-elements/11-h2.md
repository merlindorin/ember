# h2

![Settings in bold, half as large again as the line of body text under it](h2.png "ember · h2")

```go
ui.H2(ui.Text("Settings"))
ui.P(ui.Text("Sound, controls and display."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

| Default CSS | |
|---|---|
| `h2` | `display: block; margin: 0.83em 0; font-size: 1.5em; font-weight: bold` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element h2
```
