# th

![A score table: the header cells Player, Score and Time, bold and centred](table.png "ember · table")

```go
ui.Th(ui.Text("Score"), ui.Attr("aria-sort", "descending"))
```

| Attribute | |
|---|---|
| `aria-sort` | `none`, `ascending` or `descending`: in a grid, a press sorts by its column, ascending then reversed; one past a spanning title sorts its own column |
| `colspan`, `rowspan` | it spans that many columns and rows; a `rowspan` stops at the end of its row group, and `0` spans to it |

| Default CSS | |
|---|---|
| `th` | `padding: 1px; font-weight: bold; text-align: center` |

| Event | When |
|---|---|
| `ui.Clicked{Node}` | a sorting header pressed |
| `ui.Sorted{Node, Column, Descending}` | then, for its grid |

Automation: a grid's sorting header, by its `id`, else `data-name`, `aria-label`, then the slug of its text (`score`); `press`.
