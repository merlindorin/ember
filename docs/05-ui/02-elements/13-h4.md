# h4

![Gamepad in bold, the size of the line of body text under it](h4.png "ember · h4")

```go
ui.H4(ui.Text("Gamepad"))
ui.P(ui.Text("Hold South to sprint."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

| Default CSS | |
|---|---|
| `h4` | `display: block; margin: 1.33em 0; font-size: 1em; font-weight: bold` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element h4
```
